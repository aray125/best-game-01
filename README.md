Lumenkeeper, a 2D canvas arcade game: guide the keeper, light the lanterns, gather embers and keep the wisps from snuffing the light. Plain static files — no libraries, no network — with synthesised WebAudio sound.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
